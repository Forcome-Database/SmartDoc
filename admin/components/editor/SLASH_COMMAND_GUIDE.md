# Slash 命令使用指南

## 概述

Slash 命令是一个类似 Notion 的快速插入功能，让你可以通过输入 `/` 快速插入各种 Markdown 元素。

## 快速开始

### 1. 触发命令面板

在编辑器中输入 `/`（必须在行首或空格后），会自动弹出命令面板。

```
# 示例
/           ← 在行首输入
Hello /     ← 在空格后输入
```

### 2. 搜索命令

输入 `/` 后继续输入关键词可以过滤命令：

```
/h1         ← 搜索标题
/code       ← 搜索代码块
/表格       ← 中文搜索
```

### 3. 选择命令

- 使用 `↑` `↓` 键在命令列表中导航
- 按 `Enter` 选择当前高亮的命令
- 按 `Esc` 关闭命令面板
- 用鼠标点击也可以选择命令

## 可用命令

### 标题类

| 命令 | 关键词 | 插入内容 |
|------|--------|----------|
| 一级标题 | `/h1`, `/heading`, `/标题` | `# ` |
| 二级标题 | `/h2`, `/heading`, `/标题` | `## ` |
| 三级标题 | `/h3`, `/heading`, `/标题` | `### ` |

### 文本格式

| 命令 | 关键词 | 插入内容 |
|------|--------|----------|
| 粗体 | `/bold`, `/粗体` | `**粗体文本**` |
| 斜体 | `/italic`, `/斜体` | `*斜体文本*` |
| 代码块 | `/code`, `/代码` | ` ```javascript\n// 代码\n``` ` |

### 列表

| 命令 | 关键词 | 插入内容 |
|------|--------|----------|
| 无序列表 | `/list`, `/列表` | `- ` |
| 有序列表 | `/ordered`, `/有序` | `1. ` |
| 任务列表 | `/task`, `/todo`, `/任务` | `- [ ] ` |

### 内容块

| 命令 | 关键词 | 插入内容 |
|------|--------|----------|
| 引用 | `/quote`, `/引用` | `> ` |
| 表格 | `/table`, `/表格` | 3x2 表格模板 |
| 分割线 | `/divider`, `/hr` | `---` |

### 媒体

| 命令 | 关键词 | 插入内容 |
|------|--------|----------|
| 链接 | `/link`, `/链接` | `[链接文本](url)` |
| 图片 | `/image`, `/图片` | `![描述](url)` |

### 提示框

| 命令 | 关键词 | 插入内容 |
|------|--------|----------|
| 信息提示 | `/info`, `/callout` | `> [!NOTE]` |
| 警告提示 | `/warning`, `/callout` | `> [!WARNING]` |
| 技巧提示 | `/tip`, `/callout` | `> [!TIP]` |

## 使用技巧

### 1. 快速插入标题

```markdown
/h1
# 一级标题

/h2
## 二级标题
```

### 2. 快速创建列表

```markdown
/list
- 列表项 1
- 列表项 2

/task
- [ ] 待办事项 1
- [ ] 待办事项 2
```

### 3. 插入代码块

```markdown
/code
```javascript
console.log('Hello World')
```
```

### 4. 创建表格

```markdown
/table
| 列1 | 列2 | 列3 |
| --- | --- | --- |
| 内容 | 内容 | 内容 |
```

### 5. 添加提示框

```markdown
/info
> [!NOTE]
> 这是一条重要信息

/warning
> [!WARNING]
> 请注意这个警告

/tip
> [!TIP]
> 这是一个实用技巧
```

## 自定义命令

如果你需要添加自定义命令，可以编辑 `SlashCommandPanel.vue` 文件：

```typescript
// admin/components/editor/SlashCommandPanel.vue

const commands: SlashCommand[] = [
  // ... 现有命令
  
  // 添加你的自定义命令
  {
    id: 'my-custom-command',
    label: '我的命令',
    description: '插入自定义内容',
    icon: 'i-lucide-star',
    keywords: ['custom', '自定义', 'my'],
    action: () => '自定义内容',
  },
]
```

## 常见问题

### Q: 为什么输入 `/` 没有弹出面板？

A: 确保 `/` 是在行首或空格后输入的。如果在单词中间输入 `/` 不会触发命令面板。

### Q: 如何关闭命令面板？

A: 按 `Esc` 键或点击编辑器其他区域。

### Q: 可以用鼠标选择命令吗？

A: 可以，直接点击命令即可选择。

### Q: 命令面板支持中文搜索吗？

A: 支持！你可以输入中文关键词来搜索命令。

### Q: 如何修改命令的插入内容？

A: 编辑 `SlashCommandPanel.vue` 中对应命令的 `action` 函数。

## 技术细节

### 实现原理

1. **内容监听**：监听编辑器内容变化
2. **模式匹配**：检测 `/` 字符及其位置
3. **位置计算**：获取光标在屏幕上的坐标
4. **面板渲染**：使用 Teleport 渲染到 body
5. **内容替换**：选择命令后替换 `/` 及搜索文本
